# Projet Vestige
Demo du projet Vestige réalisé sous Unity dans le cadre de mes études en AMINJ.
Le jeu consiste à reprendre les codes des vieux donjons du style Zelda Ocarina of Time ou même Zelda Skyward Sword, afin de réaliser différents puzzles et parcours qui vous replonge dans l'ancien temps des jeux d'aventures.

Vous êtes donc un aventurier parcourant les anciens Vestiges d'une population vénérant l'espèce des scarabées.

## Commandes de jeu
• ZQSD pour le déplacement
• Espace pour effectuer une roulade
• Espace proche d'un bord accessible pour grimper
• Le saut s'effectue automatiquement lorsque vous êtes proche d'un bord
• E pour utiliser un objet / Encore E pour valider l'utilisation ou Espace pour annuler
• Clique gauche pour attaquer
• Molette pour corriger la distance de la caméra
• Echap pour afficher le menu pause

## Avertissement
Ce projet a été réalisé en moins de 2 mois sans équipe, il existe donc de possibles "bugs" de collisions ou de comportement que je n'ai pas prévu lors de la réalisation puisqu'il fallait respecter une courte deadline.
Si vous rencontrez un souci, faites Echap puis quitter sans sauvegarder, ce qui vous ramènera au point de sauvegarde automatique le plus proche.
